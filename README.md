### Resume
Личное резюме, созданное как стартовый milestone для отслеживания прогресса в сфере веб-разработки. Информация, представленная в нём являлась актуальной на момент октября 2025 года.

## Описание
Целью данной работы было закрепление основ языка разметки html, языка стилей css и общего умения располагать элементы на странице.

Вся личная информация, представленная на сайте является выдуманной/недействительной.

Проект был создан в качестве первого домашнего задания на курсах дополнительного образования от IT-академии Samsung по фуллстек разработке.

## Установка
Для запуска проекта достаточно выполнить одно из двух:
- Опробовать интернет-ресурс через ссылку на git-deploy
- Клонировать репозиторий и открыть файл "index.html"
